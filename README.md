# 靈環覺醒：靈印放置錄

一款純前端、零建置的直式放置型 RPG。自動掛機打靈獸 → 升級 → 獵靈吸收靈環 → 突破等級上限 → 挑戰 BOSS 推進關卡。
**沒有任何後端**：存檔在瀏覽器 `localStorage`，可匯出／匯入存檔碼換裝置。

> 原創名稱與美術（幾何／emoji），玩法向靈印靈環題材致敬，不含任何原作素材。

## 直接玩

- 線上版：<https://bodhi16889.github.io/soul-ring-h5/>
- 本機：`python3 -m http.server 8080` 後開 <http://localhost:8080>

## 怎麼玩

| 系統 | 說明 |
|---|---|
| 自動戰鬥 | ATB 行動條（約 0.8 秒出手一次），靈印自動普攻，靈力滿自動放靈技（強攻／控制／防禦／輔助四系） |
| 放置自動化 | 清完小怪 1.8 秒後自動挑戰 BOSS、卡等自動獵靈、靈環自動裝備（三項都能在設定關掉） |
| 多波小怪 | 第 3 關起一波可能 1–3 隻（多隻時單隻較弱）；強攻系靈技打全體，群攻才有價值 |
| Boss 被動 | 血量 ≤40% 狂暴一次（攻擊 +35%）；血量 <70% 時每 5 次行動回復 8% 生命 |
| 關卡 | 無限關卡：每關清 8 隻小怪 → 守關靈獸 → 通關進下一關；地圖每 10 關輪替 |
| 轉生 | 歷史最高 ≥20 關可轉生，換「命印」（每點全屬性 +6%、收益 +4%）；重置本輪但保留靈印/星級/靈骨 |
| 升級 | 等級上限固定 100；每 10 級開 1 個靈環槽（最多 9 格） |
| 獵靈 | 幽篁林五種靈獸：十年／百年／千年／萬年／十萬年，擊敗掉落對應靈環 |
| 靈環 | 白 10% → 黃 25% → 紫 60% → 黑 150% → 紅 400% 攻擊與生命加成 |
| 環槽 | 每個靈印最多 9 格，**每 10 級開 1 格**（Lv10=1、Lv100=9） |
| 靈環技能 | 千年以上靈環自帶靈技（千年群體 120%、萬年震懾 150%、十萬年群體 200%） |
| 屬性共鳴 | 同一靈印 3 個同系靈環 → 該系靈技傷害 +25% |
| 靈印真身 | 同一靈印 3/6/9 個萬年以上靈環 → 全屬性 ×1.15 / ×1.35 / ×1.60 |
| 靈環合成 | **3 個同階 → 1 個高一階**（白→黃→紫→黑→紅，紅為頂不再合）；只吃未裝備的環 |
| 一鍵合成 | 靈環頁一顆按鈕，把白／黃／紫／黑全部合到不能再合 |
| 自動合成 | 預設開啟，只合十年／百年（保護千年以上，讓你自己決定要不要衝真身） |
| 陣容 | 最多 5 人小隊，用靈幣＋等級解鎖名額 |
| 覺醒 | 靈印殿抽卡（覺醒券／鑽石），重複靈印自動升星 |
| 靈骨 | 抽卡可抽出靈骨（攻擊／生命／防禦／速度／全屬性）；裝備者吃全額，同隊其他靈印吃 30% 光環 |
| 升星 | 靈印升星消耗**未裝備的靈骨**＋靈幣（3→4 需 1 塊、4→5 需 2 塊），上限 5★ |
| 離線 | 關掉頁面也會累積靈幣與經驗，上限 12 小時 |
| 簽到 | 每日簽到 7 天一輪：靈幣 / 鑽石 / 覺醒券 / 黃靈環，第 7 天給黑靈環＋888 鑽；斷簽從第 1 天重來 |
| 兌換碼 | `VIP666`、`DOULUO888`、`TANG3` |

## 轉生（命印）設計

```
條件    歷史最高關卡 ≥ 20
收益    命印 = floor(最高關卡/5) + floor(等級/10)
效果    每點命印：攻擊/生命/防禦 +6%、速度 +2%、靈幣與經驗 +4%
重置    等級、經驗、關卡、靈幣、靈環（含背包）
保留    靈印與星級、靈骨、命印、最高關卡、簽到與兌換碼
```

轉生後戰力通常**不降反升**（命印加成 > 等級重置損失），這就是放置遊戲的「越轉越強」曲線。
實測：35 關、Lv34、4★ 轉生 → 得 10 命印，戰力 185 → 274、收益 ×1.40。

## 無限關卡的難度曲線

`js/config.js` 的 `stageMul(stage, 1.16, 1.06, 60)`：

- 前 60 關：×1.16 指數成長（前期有壓力）
- 60 關之後：改成 ×1.06（深關不會變成天文數字；原本第 400 關怪物血量 2.2e27，現在約 1e14）
- 地圖名稱每 10 關輪替（8 個場景循環），關卡數字本身沒有上限

### 轉生規則（v1.4.4 起）

- 收益只看**本輪推進**：`gain = floor((最高關卡 − 上次轉生時的最高關卡) / 5) + floor(等級 / 20)`
- **必須刷新最高關卡才能轉生**（停在同一關不能轉），避免「原地按轉生領命印」
- 轉生後記錄 `lastRebirthBest`，下一次要再推更深
- 轉生保留：靈印、星級、靈骨、靈環、命印；重置：等級、關卡、靈幣
- 每次轉生起始等級 +5（上限 60）

### 難度（v1.4.4 起）

- 深度放寬：第 100 關之後每 150 關，怪物血量上限 ×1（最多 ×1.4），防禦放寬一半，攻擊不放寬
- BOSS 連敗削弱：每次失敗血量上限 ×0.82（最多 5 次）

### 靈幣出口（v1.5.0 起）

- 靈印頁「靈骨」區新增 **靈幣抽靈骨**：每次必得 1 塊，王者（全屬性）較稀有
- 成本遞增：`2000 × 1.35^已抽次數`（第 1 次 2,000、第 20 次約 80 萬、第 40 次約 3.2 億）
- 可單抽或連抽 5 次（逐次計價；錢不夠只完成付得起的次數，不會扣成負數）
- `bonePulls` 存入存檔，舊存檔自動補 0

### P1（v1.7.0）

- **戰力換速度**：實際 DPS 超過該關所需時，戰鬥時間最低降到 60%（最多快 1.67 倍）
- **靈印獨立等級**：靈幣升級，上限＝玩家等級 +20（最高 150）；費用 `300 × Lv^1.9`
- **每日任務**：掛機 10 分 / 獵靈 3 次 / 合成 3 次 → 60/60/80 鑽石，每日 0 點重置

### P1 後半 + P2（v1.8.0）

- **成就 12 項**：達標自動解鎖，每項永久 +0.5% 全屬性（乘算），覺醒頁可看進度
- **里程碑**：每推進到 50 的倍數關卡送一個十萬年靈環
- **音效**：WebAudio 即時合成（零素材），設定頁可開關；廣告／切頁自動 suspend
- **紀錄牆**：設定頁顯示最高關卡／最高戰力／轉生／命印／累計擊殺／獵靈／連續簽到／成就數
