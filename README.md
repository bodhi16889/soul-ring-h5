# 魂環覺醒：武魂放置錄

一款純前端、零建置的直式放置型 RPG。自動掛機打魂獸 → 升級 → 獵魂吸收魂環 → 突破等級上限 → 挑戰 BOSS 推進關卡。
**沒有任何後端**：存檔在瀏覽器 `localStorage`，可匯出／匯入存檔碼換裝置。

> 原創名稱與美術（幾何／emoji），玩法向武魂魂環題材致敬，不含任何原作素材。

## 直接玩

- 線上版：<https://bodhi16889.github.io/soul-ring-h5/>
- 本機：`python3 -m http.server 8080` 後開 <http://localhost:8080>

## 怎麼玩

| 系統 | 說明 |
|---|---|
| 自動戰鬥 | ATB 行動條（約 0.8 秒出手一次），武魂自動普攻，魂力滿自動放魂技（強攻／控制／防禦／輔助四系） |
| 放置自動化 | 清完小怪 1.8 秒後自動挑戰 BOSS、卡等自動獵魂、魂環自動裝備（三項都能在設定關掉） |
| 多波小怪 | 第 3 關起一波可能 1–3 隻（多隻時單隻較弱）；強攻系魂技打全體，群攻才有價值 |
| Boss 被動 | 血量 ≤40% 狂暴一次（攻擊 +35%）；血量 <70% 時每 5 次行動回復 8% 生命 |
| 關卡 | 無限關卡：每關清 8 隻小怪 → 守關魂獸 → 通關進下一關；地圖每 10 關輪替 |
| 轉生 | 歷史最高 ≥20 關可轉生，換「魂印」（每點全屬性 +6%、收益 +4%）；重置本輪但保留武魂/星級/魂骨 |
| 升級 | 等級上限固定 100；每 10 級開 1 個魂環槽（最多 9 格） |
| 獵魂 | 星斗大森林五種魂獸：十年／百年／千年／萬年／十萬年，擊敗掉落對應魂環 |
| 魂環 | 白 10% → 黃 25% → 紫 60% → 黑 150% → 紅 400% 攻擊與生命加成 |
| 環槽 | 每個武魂最多 9 格，**每 10 級開 1 格**（Lv10=1、Lv100=9） |
| 魂環技能 | 千年以上魂環自帶魂技（千年群體 120%、萬年震懾 150%、十萬年群體 200%） |
| 屬性共鳴 | 同一武魂 3 個同系魂環 → 該系魂技傷害 +25% |
| 武魂真身 | 同一武魂 3/6/9 個萬年以上魂環 → 全屬性 ×1.15 / ×1.35 / ×1.60 |
| 陣容 | 最多 5 人小隊，用魂幣＋等級解鎖名額 |
| 覺醒 | 武魂殿抽卡（覺醒券／鑽石），重複武魂自動升星 |
| 魂骨 | 抽卡可抽出魂骨（攻擊／生命／防禦／速度／全屬性）；裝備者吃全額，同隊其他武魂吃 30% 光環 |
| 升星 | 武魂升星消耗**未裝備的魂骨**＋魂幣（3→4 需 1 塊、4→5 需 2 塊），上限 5★ |
| 離線 | 關掉頁面也會累積魂幣與經驗，上限 12 小時 |
| 簽到 | 每日簽到 7 天一輪：魂幣 / 鑽石 / 覺醒券 / 百年魂環，第 7 天給萬年魂環＋888 鑽；斷簽從第 1 天重來 |

## 專案結構（零建置：Push 即上線）

```
soul-ring-h5/
├── index.html          # UI 骨架（頂部狀態列 / 舞台 / 五個頁籤 / 彈窗）
├── css/style.css       # 9:16 直式版面、魂環光圈與飄字動畫
├── js/
│   ├── config.js       # 武魂、魂獸、魂環、關卡、抽卡、兌換碼等數值表
│   ├── state.js        # 存檔、衍生數值、離線收益、存檔碼匯出／匯入
│   ├── battle.js       # ATB 自動戰鬥、技能與狀態、關卡推進、獵魂
│   └── ui.js           # 渲染、事件、飄字、光圈、彈窗
├── tests/smoke.py      # 23 項端到端驗證（Playwright）
└── artifacts/          # 測試截圖
```

沒有任何 `npm install`、沒有打包步驟，GitHub Pages 直接吃根目錄。

## 轉生（魂印）設計

```
條件    歷史最高關卡 ≥ 20
收益    魂印 = floor(最高關卡/5) + floor(等級/10)
效果    每點魂印：攻擊/生命/防禦 +6%、速度 +2%、魂幣與經驗 +4%
重置    等級、經驗、關卡、魂幣、魂環（含背包）
保留    武魂與星級、魂骨、魂印、最高關卡、簽到與兌換碼
```

轉生後戰力通常**不降反升**（魂印加成 > 等級重置損失），這就是放置遊戲的「越轉越強」曲線。
實測：35 關、Lv34、4★ 轉生 → 得 10 魂印，戰力 185 → 274、收益 ×1.40。

## 無限關卡的難度曲線

`js/config.js` 的 `stageMul(stage, 1.16, 1.06, 60)`：

- 前 60 關：×1.16 指數成長（前期有壓力）
- 60 關之後：改成 ×1.06（深關不會變成天文數字；原本第 400 關怪物血量 2.2e27，現在約 1e14）
- 地圖名稱每 10 關輪替（8 個場景循環），關卡數字本身沒有上限

## 目前節奏（實測，從全新存檔開始放置）

| 里程碑 | 時間 |
|---|---|
| Lv.10（等級上限） | **約 79 秒** |
| 第一枚魂環（十年） | **約 89 秒** |
| 第 5 關 | 約 5 分鐘 |
| 第 2 枚魂環（百年，Lv20） | 約 8–12 分鐘 |

量測方式：`/usr/bin/python3 tests/pacing.py --label after`（自動玩到拿環，輸出 `artifacts/pacing-*.json`）。

調整前是 Lv10 要 **222 秒**、6 分鐘還拿不到第一枚魂環，而且會卡在「打不贏第 1 關 BOSS → 重來」的迴圈。

## 想調平衡

全部集中在 `js/config.js`：

- `SOULS`：武魂基礎攻擊／生命／防禦／速度與定位
- `BEASTS`：魂獸血量與冷卻、掉落年份
- `RING_TIERS`：魂環加成倍率
- `expNeed()` / `levelCap()` / `enemyStats()` / `killReward()` / `offlinePerMinute()`：成長曲線
- `SLOT_COST` / `SLOT_LEVEL`（在 `state.js`）：陣容解鎖成本
